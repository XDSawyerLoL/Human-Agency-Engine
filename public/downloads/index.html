IDENTITÉ

Quantic Identity Vault 0.4.0

Windows

Le compagnon local de Quantic ID. La v0.4.0 conserve le mode USB sans code et ajoute Quantic Hardware Key QHK/1 : avec un périphérique compatible équipé d’un élément sécurisé, la clé privée ne quitte jamais le matériel. Une simple clé USB de stockage reste disponible en mode standard.
